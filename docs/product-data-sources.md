# Источники данных по продуктам

## КБЖУ

Каталог `src/catalog/products.json` теперь собирается по официальным USDA FoodData Central dumps, локально, без массовых live-запросов к API:

- USDA FoodData Central download datasets: https://fdc.nal.usda.gov/download-datasets/
- USDA API guide: https://fdc.nal.usda.gov/api-guide

В проекте для расширения каталога используется локальный генератор:

- `scripts/expand-product-catalog.mjs`

Он работает от двух выгрузок USDA:

- `FoundationFoods`
- `SRLegacyFoods`

Приоритет такой:

1. локальный матч по USDA Foundation / SR Legacy
2. если совпадения нет, продукт не попадает в расширенный каталог

Это сделано специально, чтобы не упираться в rate limits `DEMO_KEY` и не плодить случайные live-match'и.

## Цены и `priceCategory`

`priceCategory` в каталоге не приходит из USDA. Это отдельная прикладная категоризация `CHEAP / MID / HIGH`, откалиброванная по российским региональным источникам за 2025-2026, без Москвы как базового ориентира.

Базовые регионы для ориентиров:

- Омск
- Новосибирск
- Красноярск
- Краснодар
- Санкт-Петербург

Опорные официальные источники:

- Росстат, индекс потребительских цен и средние потребительские цены: https://rosstat.gov.ru/
- Омскстат: https://55.rosstat.gov.ru/
- Новосибирскстат: https://54.rosstat.gov.ru/
- Красноярскстат: https://24.rosstat.gov.ru/
- Краснодарстат: https://23.rosstat.gov.ru/
- Петростат / Санкт-Петербург: https://78.rosstat.gov.ru/folder/190263

Практическая логика для `priceCategory`:

- `CHEAP`: массовые и недорогие позиции для повседневного рациона в регионах
- `MID`: средний сегмент без выраженной премиальности
- `HIGH`: дорогие белки, орехи, ягоды, часть рыбы и более дорогие снеки

Дополнительно для spot-check использовались региональные ритейл-ориентиры уровня федеральных сетей с региональной витриной и акциями марта 2026. Они нужны не как источник истины по КБЖУ, а как sanity-check для разнесения по ценовым сегментам.

## Что важно

- USDA отвечает только за нутриенты
- `priceCategory` — это внутренняя бизнес-классификация проекта
- каталог расширяется только теми продуктами, которые удалось нормально сматчить к USDA локально
